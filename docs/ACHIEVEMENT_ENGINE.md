# Achievement Engine — Архитектура

## Обзор

`js/achievements.js` — центральная система достижений платформы MathLogic.

Achievement Engine автоматически:
- слушает события приложения
- отслеживает прогресс по каждому достижению
- разблокирует достижения при выполнении условий
- начисляет XP за каждое разблокированное достижение
- добавляет запись в timeline
- показывает toast-уведомление
- обновляет счётчик `stats.achievements_count`

---

## API

### `Achievements.init()`
Принудительная инициализация. Вызывается автоматически при загрузке модуля.

### `Achievements.check(eventName, payload)`
Проверяет все достижения на предмет выполнения условий. Вызывается движком автоматически при событиях, но может быть вызван вручную.

| Параметр    | Тип     | Описание                          |
|-------------|---------|-----------------------------------|
| `eventName` | string  | Имя события (`lesson:completed`, `xp:update`, и т.д.) |
| `payload`   | object  | Детали события (опционально)       |

### `Achievements.unlock(id)`
Принудительная разблокировка достижения по ID. Начисляет XP и создаёт записи. Возвращает `true`/`false`.

### `Achievements.isUnlocked(id)`
Проверяет, разблокировано ли достижение. Возвращает `true`/`false`.

### `Achievements.getAll()`
Возвращает массив всех достижений с текущим состоянием.

### `Achievements.getUnlocked()`
Возвращает массив только разблокированных достижений.

### `Achievements.getProgress(id)`
Возвращает прогресс по конкретному достижению:

```js
{
  progress: 5,    // текущее значение
  total: 10,      // целевое значение
  completed: false
}
```

### `Achievements.getStats()`
Возвращает общую статистику:

```js
{
  total: 28,                       // всего достижений
  unlocked: 3,                     // разблокировано
  progress: 11,                    // процент выполнения
  totalXpEarned: 350,             // суммарно XP получено
  byRarity: {
    common:    { total: 12, unlocked: 2 },
    rare:      { total: 8,  unlocked: 1 },
    epic:      { total: 6,  unlocked: 0 },
    legendary: { total: 2,  unlocked: 0 },
  }
}
```

## Структура данных

### Хранилище

```
mathlogic_data
└── achievements: [...]
```

Путь в localStorage: `mathlogic_data → achievements` (массив объектов).

### Поля каждого достижения

| Поле         | Тип      | Описание                                |
|--------------|----------|-----------------------------------------|
| `id`         | string   | Уникальный идентификатор                |
| `name`       | string   | Название достижения                     |
| `desc`       | string   | Описание (показывается при unlocked)    |
| `icon`       | string   | Emoji-иконка                            |
| `rarity`     | string   | Редкость (`common`, `rare`, `epic`, `legendary`) |
| `condition`  | string   | Условие получения (показывается locked) |
| `status`     | string   | `locked` | `in-progress` | `unlocked`   |
| `progress`   | number   | Текущий прогресс                        |
| `total`      | number   | Целевое значение                        |
| `date`       | string   | Дата разблокировки (null если locked)   |
| `rewardXP`   | number   | XP за разблокировку                     |
| `hidden`     | boolean  | Скрытое достижение                      |
| `completed`  | boolean  | Флаг завершения                         |
| `completedAt`| number   | Timestamp разблокировки (null если locked) |

## События

Engine автоматически слушает следующие события:

| Событие              | Когда срабатывает          | Источник        |
|----------------------|----------------------------|-----------------|
| `lesson:completed`   | Урок завершён              | `learning.js`   |
| `xp:update`          | XP изменён                 | `xp.js`         |
| `progress:update`    | Прогресс обновлён          | `learning.js`   |
| `quest:completed`    | Daily Quest выполнен       | *(будущий модуль)* |
| `streak:update`      | Серия обновлена            | *(будущий модуль)* |

Engine также генерирует событие:

| Событие              | Детали                              | Когда срабатывает          |
|----------------------|-------------------------------------|----------------------------|
| `achievement:unlock` | `{ id, name }`                      | Достижение разблокировано  |

## Защита от повторного получения

- Одно достижение нельзя получить дважды: проверка `if (ach.completed) return;`
- XP за достижение начисляется только один раз: награда выдаётся в момент `completed → true`
- При повторном вызове `Achievements.unlock(id)` для уже разблокированного — возвращает `false`

## Как добавить новое достижение

1. Добавить объект в массив `DEFINITIONS` в `achievements.js`
2. Добавить обработку `case 'new_id':` в `check()` функции
3. Документация обновится автоматически... (нет, но опционально)

Формат определения:

```js
{
  id: 'new_achievement',
  title: 'Название',
  desc: 'Описание при получении',
  condition: 'Условие в заблокированном виде',
  icon: '🏆',
  rarity: 'rare',        // common | rare | epic | legendary
  target: 10,            // целевое значение
  hidden: false,
}
```
